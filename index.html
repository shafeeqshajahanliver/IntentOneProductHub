Infrastructure
Decided pre-contract
Where must the application and the data live?

Red Box. Dedicated single-tenant, priced cost-plus. Architecture review before any commercial commitment; typically 2–4 months to live.

Their cloud, or on-prem?

Dedicated environment in the client's own account, run on OpenShift — they own account, network and data plane; we operate it remotely. Databricks by default, our equivalent layer where it isn't available. Customer-managed keys supported.

Which cloud?

Live. ROSA (OpenShift on AWS) reference architecture — the proven pattern.

Live. ARO reference architecture; MTN South Africa is the working pattern (site-to-site VPN back to our AWS).

Landing Sep 2026. GKE route being built with Searce (Google-funded), BT first. Red Box on GCP is feasible now on this pattern.

Software appliance on client hardware — Kubernetes/OpenShift, can run fully air-gapped; NexusOne provides the cloud-equivalent services (MTN Nigeria is the live pattern). Slowest start: hardware must be procured, racked and networked before anything else.

Client provides: racked hardware to our spec (NX1: 3-node cluster + all-flash S3 storage, one rack), network segmentation and firewalls, power/cooling, and a patching channel. We provide: packaged images, install tooling and install support.

How will our engineers access the environment?

Client-provisioned bastion host or virtual desktop — the standard, fully auditable path.

Scoped site-to-site VPN or scheduled connectivity windows — the MTN pattern.

Everything inside the client's own workspace, every release through their change process — the Verizon (Citrix) pattern. Slowest cadence; price the ops burden in.

No inbound access at all: the client initiates every connection and exports diagnostics. Supported, but it changes the integration design — establish this early.

Blue Box. Shared multi-tenant platform on a supported region — the default classification. Configuration only, published pricing; typically 2–4 weeks from contract to first opportunity.

Data residency — where must data stay? select all that apply
Residency is met by region choice — AWS today, Azure live, GCP from Sep 2026. If no supported region fits (e.g. strict in-country rules with no local cloud), the deal is Red Box.

The opportunity agents generate a ranked, explained stream from the client's goals on a schedule. CS runs a regular hub review with the client — tune goals, activate the top opportunities, retire the rest.

Campaign managers build and refine opportunities in chat. We enable their team — prompt patterns, targeting controls and exclusions, creative review — until the habit sticks.
